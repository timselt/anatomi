# Anatomi Çalışma Masası

Tarayıcıda çalışan, Türkçe arayüzlü 3 boyutlu insan anatomisi çalışma aracı: https://timselt.github.io/anatomi/

Kişisel ve eğitim amaçlıdır; ticari değildir, tanı ya da tedavi aracı değildir. Kullanım: `KULLANIM.md`.

## Kaynaklar ve lisanslar
- Erkek beden modeli: BodyParts3D, © The Database Center for Life Science, CC BY 4.0 (tarayıcıya hazır dosyalar: ashemag/human-atlas, MIT).
- Kadın beden modeli: Kristen Browne ve Heidi Schlehlein, Human Reference Atlas / HuBMAP, 3D Reference Organ Set for Female v1.5, CC BY 4.0.
- Ek katman (sinirler, lenf düğümleri, akciğer lobları): Z-Anatomy, CC BY-SA 4.0 (BodyParts3D türevi; dönüştürülmüş dosyalar: nqwrc/3d-anatomy). İçindeki "Anatomy of the Inner Ear" (University of Dundee, CC BY-NC-SA 4.0) ve "Kidney" (lissiecowley, CC BY-NC 4.0) ticari olmayan lisanslıdır. `data/models/zanatomy/` klasöründeki veri CC BY-SA 4.0 ile paylaşılır.
- three.js: MIT.

Lisans metinleri `lisanslar/` klasöründedir.
